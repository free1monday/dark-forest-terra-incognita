# Client — Тёмный Лес: Терра Инкогнита (Этап 1)

Vite + React + TypeScript + Zustand.

## Запуск

```bash
# из корня репозитория
npm run dev

# или
cd client && npm install && npm run dev
```

Откройте http://localhost:5173

## Что умеет прототип

- Создание цивилизации + константы
- Seeded worldgen (галактика, сектор, система, аномалии, радар)
- 5 ресурсов (активны Высокие энергии)
- Тик производства 1с + localStorage
- Постройки и апгрейды
- Уровень цивилизации
- Инспектор объектов
- Экспедиция «Терра Инкогнита»
- Технический журнал
- DEBUG-панель

Общие формулы: `../shared/src`
