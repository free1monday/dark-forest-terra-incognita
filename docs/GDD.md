# Game Design Document — Тёмный Лес: Терра Инкогнита

## 1. Концепция

**Жанр:** idle strategy + MMO RPG  
**Тон:** научная фантастика, космическая социология, тёмный лес  
**Платформа:** браузер (десктоп-first)

Игрок создаёт цивилизацию в процедурно сгенерированной точке Вселенной. Цель — максимальное **Процветание** при постоянной угрозе обнаружения и уничтожения другими цивилизациями.

Ключевой принцип вселенной (слоган):

> Вселенная детерминирована, вероятностна и не случайна.

Случайность существует, но подчиняется скрытым правилам и seed. Игрок ощущает вероятностный, но не хаотичный мир.

## 2. Фантазия игрока

Игрок — **бог-основатель**:

1. Задаёт начальные константы цивилизации.
2. Развивает технологии, постройки, уровень.
3. Исследует Терру Инкогниту.
4. Обнаруживает другие цивилизации.
5. Дипломатия / обман / тёмный удар.
6. На поздних этапах — меняет локальные законы физики и создаёт системы из фермионов.

## 3. Вселенная (слои)

1. **Великие структуры** — Великая стена Слоуна, Войд Волопаса, Сверхскопление Шепли, Великий аттрактор и др.
2. **Галактики**
3. **Сектора**
4. **Солнечные системы**
5. **Объекты:** планеты, аномалии, чёрные дыры, нейтронные звёзды, червоточины, тёмные облака, 4D-разломы

Каждая цивилизация появляется в случайной (seeded) галактике / секторе / системе на пригодной планете.

### Параметры системы (генерация)

| Параметр | Описание |
|----------|----------|
| galaxyName | Название галактики |
| greatStructureName | Ближайшая великая структура |
| sectorName | Сектор |
| systemName | Солнечная система |
| coordinates | (x, y, z) |
| starType | Тип звезды |
| planetCount | Число планет |
| habitability | непригодная / пригодная / идеальная |
| anomalyType | Аномалия (или none) |
| backgroundRadiation | Фоновая радиация |
| vacuumStability | Стабильность вакуума |
| darkMatterDensity | Плотность тёмной материи |
| eventProbability | Базовый множитель событий |
| radarQuality | «Радар/Локация» — шанс ресурсов, артефактов, опасностей |

## 4. Ресурсы

| ID | Название | Роль | Покупка |
|----|----------|------|---------|
| highEnergy | Высокие энергии | Базовое развитие 1–60, исследования, сканирование, зонды | ✅ да |
| antimatter | Антиматерия | Флот, экспедиции, бой, продвинутые постройки | ❌ нет |
| darkEnergy | Тёмная энергия | Уровни 61+, межгалактика, локальная физика | ❌ нет |
| darkMatter | Тёмная материя | Скрытность, сенсоры, гравищиты | ❌ нет |
| fermions | Фермионы | Создание планет/систем, сверхдорогие объекты | ✅ да |

## 5. Уровни цивилизации (1–100)

- **1–60:** в основном Высокие энергии.
- **61+:** + Тёмная энергия и прочие ресурсы.
- **90+:** изменение локальных законов физики (c, энтропия, вакуум, гравитация, маскировка, причинность, карманные измерения, фундаментальные силы).

**MVP (Этап 1):** уровни 1–10 полноценно; формула до 100; заготовки 60+/90+.

## 6. Константы цивилизации

Задаются при создании (0–100):

| Константа | Эффект (направление) |
|-----------|----------------------|
| scienceFocus | Скорость исследований, точность сенсоров |
| expansionFocus | Производство, колонии, стоимость экспансии |
| secrecy | Скрытность, шанс быть обнаруженным |
| aggression | Сила атаки, дипломатический риск |
| diplomacyFocus | Доверие, успех пактов |
| riskLevel | Шанс редких находок и опасных событий |

## 7. Основной геймплей

Idle + активные действия:

- распределение ресурсов, постройки, исследования;
- зонды, сканирование, Терра Инкогнита;
- послания, договоры, атаки, скрытие;
- межгалактика (поздно);
- создание планет/систем из фермионов (поздно).

Каждый объект кликабелен → панель: название, описание, характеристики, уровень, стоимость, эффекты, действия.

## 8. Терра Инкогнита

Любая неизвестная область = «Терра Инкогнита».

Результаты экспедиции (примеры): пусто, следы цивилизации, ресурсы, аномалия, ЧД, червоточина, тёмное облако, 4D-разлом, артефакт, легендарный предмет, координаты цивилизации, ловушка, ложный сигнал.

**Радар/Локация** влияет на шансы ресурсов, артефактов, следов цивилизаций, опасных аномалий и качество разведданных.

## 9. Обнаружение цивилизаций

Каналы: зонды, радио, нейтрино, грависенсоры, квантовые корреляции, следы ТМ, аномалии CMB.

Отчёт всегда неточен: диапазон уровня, погрешность дистанции, шум координат, % достоверности. Чем выше сенсоры — тем точнее.

## 10. Дипломатия (космическая социология)

Дипломатический кабинет: послания, карточки, пакты, ультиматумы, обман, разрыв, подготовка тёмного удара.

Расстояние критично (время сигнала, стоимость разведки/атаки). Аномалии у цели могут блокировать прямой удар.

## 11. Бой («морской бой» в космосе)

Асинхронный. Неточные координаты, скрытые сектора, разведка, удар по зонам, автозащита, технический отчёт. Факторы: уровень, тех, артефакты, дистанция, среда, ЧД, ТМ, маскировка, бюджет, тип удара.

## 12. Монетизация

- Покупаются: Высокие энергии, Фермионы (через премиум-кредиты-заглушку).
- Не покупаются: Антиматерия, ТЭ, ТМ.
- Косметика и мягкие ускорения допустимы.
- Pay-to-win базового прогресса — запрещён.

## 13. Лидерборд

Рейтинг **Процветание**: уровень, наука, системы/планеты, добыча, артефакты, договоры, победы, выживание, исследования TI, редкие открытия.

## 14. Визуальный стиль

Тёмно-синий космос, glassmorphism, cyan/blue/violet, мягкое свечение, научный минимализм. Опасность — red/purple glow. Артефакты — gold/turquoise.

## 15. Тон отчётов

Технический, сухой, научный. Пример:

> Зафиксирована активная цивилизация на расстоянии 4590 св. лет. Уровень: прибл. 34–41. Источник: нейтринный след. Достоверность: 62%.


## Этап 9 (launch polish)
